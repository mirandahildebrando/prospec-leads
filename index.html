Escolha a cidade, os bairros e os segmentos acima e clique em Gerar leads. O app busca estabelecimentos no Google Maps, mostra quem não tem site (seus leads mais quentes) e gera o link do WhatsApp com mensagem pronta.
Para ter leads sempre novos: rode de novo trocando os bairros ou os segmentos — a memória automaticamente pula quem você já viu.

Fontes de dados: Google Places API (quando configurada — dados completos: telefone, site, nota) e OpenStreetMap (gratuito, cobertura parcial no Brasil). Use com ética: identifique-se nas abordagens e respeite a recusa do contato (LGPD). Esta página não faz scraping do Google Maps — usa apenas APIs oficiais, dentro dos termos de uso.

Configuração

Sem chave, o app funciona com o OpenStreetMap (dados limitados). Com a chave do Google, você passa a receber telefone, site e nota de todas as empresas — 5.000 buscas grátis por mês.

Use {nome} para o nome do negócio e {cidade} para a cidade.

Como criar a chave do Google (leva ~10 minutos, é grátis)
  1. Abra console.cloud.google.com e crie um projeto (ex.: "prospec").
  2. Na busca do console, digite Places API (New) e clique em Ativar.
  3. No menu Credenciais → Criar credencial → Chave de API. Copie a chave.
  4. O Google pede uma conta de faturamento mesmo para o plano grátis — dentro de 5.000 buscas/mês você não paga nada. Recomendado: crie um alerta de orçamento de R$ 0 para ser avisado se algo sair do controle.
  5. Cole a chave acima e salve. Pronto — a fonte do app vira "Google Places".
